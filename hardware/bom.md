# Bill of materials

Electronic parts are purchased separately. Quantities for one device.

| Item | Spec | Notes |
|------|------|--------|
| Dev board | Waveshare **ESP32-S3-ePaper-1.54 V2** (non-touch) | **8 MB Flash + 8 MB PSRAM** (ESP32-S3-PICO-1-N8R8). Reject V1 (4/2 MB). |
| microSD | 8–32 GB, **FAT32** | Class 10 or better |
| Battery | Single-cell **3.7 V LiPo**, MX1.25 2-pin | Match connector polarity; capacity ~300–1000 mAh typical |
| USB cable | USB-C **data** | Required for flash and serial |
| Screw (optional) | M2 × 4 mm | If using a lanyard/keychain case later |
| Speaker (later) | MX1.25 2-pin, for v0.3 TTS | Not required for v0.1 |
| Filament / case | 3D print bed ≥ 140×140 mm | Optional; no STL in repo yet |

## Do not buy by mistake

- ESP32-S3-ePaper-1.54 **V1**  
- **Touch** variant (unless you later add touch support)  
- **1.54G** 4-colour sibling (different panel / some docs differ)
